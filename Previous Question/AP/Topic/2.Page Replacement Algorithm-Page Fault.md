## Topic

**Operating System (OS) → Memory Management → Virtual Memory → Page Replacement Algorithm / Page Fault**

### Exam Answer

Given:

* Page Reference String: `1, 3, 0, 3, 5, 6, 3`
* Number of Frames = `3`

If **FIFO (First-In First-Out)** Page Replacement is assumed:

| Page | Frame 1 | Frame 2 | Frame 3 | Result     |
| ---: | ------: | ------: | ------: | ---------- |
|    1 |       1 |       – |       – | Page Fault |
|    3 |       1 |       3 |       – | Page Fault |
|    0 |       1 |       3 |       0 | Page Fault |
|    3 |       1 |       3 |       0 | Hit        |
|    5 |       5 |       3 |       0 | Page Fault |
|    6 |       5 |       6 |       0 | Page Fault |
|    3 |       5 |       6 |       3 | Page Fault |

$$
\boxed{\text{Total Page Faults} = 6}
$$

**Answer: 6 Page Faults (assuming FIFO).**

> Important: Question-এ Page Replacement Algorithm-এর নাম দেওয়া নেই। তাই technically answer algorithm-এর উপর depend করে। FIFO হলে **6**, আর LRU/Optimal হলে এই reference string-এ **5** page faults হবে।

## Basic Explanation — Bangla + English

প্রথমে বুঝি **Page কী?**

একটা program যখন run করে, program-এর পুরোটা একসাথে RAM-এ রাখার প্রয়োজন হয় না। Operating System program-কে ছোট ছোট fixed-size অংশে divide করে। এই অংশগুলোকে বলে **Page**।

আর RAM-এ যেসব জায়গায় Page রাখা হয়, সেগুলোকে বলে **Frame**।

এই question-এ:

```text
3 Page Frames
```

মানে RAM-এ একসাথে maximum **3টি page** রাখা যাবে।

### Page Fault কী?

CPU যদি কোনো page চায় এবং সেই page RAM-এর frame-এ **না থাকে**, তখন তাকে disk থেকে RAM-এ আনতে হয়।

এটাই:

**Page Fault**

আর page যদি আগে থেকেই RAM-এ থাকে:

**Page Hit**

### আমাদের Reference String

```text
1, 3, 0, 3, 5, 6, 3
```

মানে CPU একে একে page চাইছে:

`1 → 3 → 0 → 3 → 5 → 6 → 3`

শুরুতে Frames empty:

```text
[ _ ] [ _ ] [ _ ]
```

CPU চাইল `1`। RAM-এ নেই।

```text
[ 1 ] [ _ ] [ _ ]
```

**Fault = 1**

তারপর `3`। নেই।

```text
[ 1 ] [ 3 ] [ _ ]
```

**Fault = 2**

তারপর `0`। নেই।

```text
[ 1 ] [ 3 ] [ 0 ]
```

**Fault = 3**

এখন সব 3টা frame full।

তারপর আবার `3` চাইল।

```text
[ 1 ] [ 3 ] [ 0 ]
```

`3` already RAM-এ আছে।

তাই এটা:

**Page Hit**

Fault এখনও **3**।

তারপর `5` চাইল।

`5` নেই এবং frame full।

FIFO মানে:

> **যে Page সবার আগে RAM-এ ঢুকেছিল, তাকে সবার আগে বের করো।**

সবার আগে এসেছিল `1`।

তাই `1` বের করে `5` বসবে:

```text
[ 5 ] [ 3 ] [ 0 ]
```

**Fault = 4**

তারপর `6` দরকার।

FIFO অনুযায়ী এখন oldest হলো `3`। তাই:

```text
[ 5 ] [ 6 ] [ 0 ]
```

**Fault = 5**

শেষে আবার `3` দরকার।

কিন্তু `3` আগেই remove হয়ে গেছে।

তাই আবার Page Fault হবে। Oldest `0` remove:

```text
[ 5 ] [ 6 ] [ 3 ]
```

**Fault = 6**

সুতরাং final answer:

$$
\boxed{6}
$$

### Exam-এর জন্য 3টা term মনে রাখুন

**Page** = Program-এর ছোট অংশ
**Frame** = RAM-এর যে slot-এ page থাকে
**Page Fault** = Required page RAM-এ না পাওয়া

আর:

**FIFO = First In, First Out**

অর্থাৎ:

> **যে page আগে ঢুকবে, replacement-এর সময় সেই page আগে বের হবে।**
