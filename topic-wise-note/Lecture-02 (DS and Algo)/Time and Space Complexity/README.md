# Time & Space Complexity — Offline Bangla Study Guide

## Start on Ubuntu Linux
1. Extract `study-guide.zip` to a folder.
2. Open `index.html` using Firefox or Chromium (double-click, or `firefox index.html`).
3. No server and no internet connection required.
4. Open `study-guide.pdf` for printing and offline reading.

## Included
- `index.html`: standalone HTML, CSS, JavaScript and self-contained SVG diagrams.
- `study-guide.pdf`: static print edition (chapters, diagrams, 46 MCQs and worked answers).
- `source-notes.md`: editable Markdown content (optional, not necessary to view guide).
- `README.md`: these instructions.

## Interactive Features
- Offline search; sidebar jump links; theme switch; expand/collapse advanced notes.
- Toggle log/linear complexity growth chart and vary maximum n.
- Step through binary search, factorial recursion and bubble/selection/insertion sorting.
- MCQ study modes: Beginner / Intermediate / Advanced; a mixed 20-question Practice Test with submit and answer key.
- Score and reset; responsive layout; print-friendly CSS.

## Fonts
The HTML uses your installed system fonts. It prefers Kohinoor Bangla and Candara if installed, otherwise Noto Sans Bengali/Lohit Bengali and Carlito/system fonts. No remote fonts are loaded.

## Important notes
Questions are original practice questions, **not verified Bangladesh government past-paper questions**.
Charts represent operation-growth functions, not measured runtime.
Big O expresses an upper bound and is not synonymous with worst-case analysis.

## Build note
The self-contained HTML uses no CDN, external image, API, third-party JavaScript or network request. All SVGs are inline.
